XML Sitemap Guide: How to Create, Optimize and Submit Sitemaps

Help search engines find your pages faster — and stop wasting crawl budget on the ones that do not matter

By the RankActions teamAugust 21, 20266 min read
In this guide
  • What belongs in a sitemap — and what should never be in one
  • Size limits, sitemap index files and compression
  • Submitting to Google and Bing, and what to monitor after

This guide will show you exactly what an XML sitemap is, why it matters for your website's visibility in search engines, and how to create, optimize, and submit one properly. XML sitemaps are one of the most straightforward yet powerful tools in technical SEO, helping search engines discover and index your content efficiently.

What Is an XML Sitemap?

An XML sitemap is a structured file that lists all the important URLs on your website along with metadata about each page, including when it was last modified, how frequently it changes, and its relative importance. This file serves as a roadmap for search engine crawlers, guiding them to the pages you want indexed.

While search engines can discover pages through internal links and external backlinks, an XML sitemap ensures that even deep or newly published pages are found quickly. It's particularly valuable for large websites, sites with complex architectures, or those with pages that aren't well-linked internally.

Key Components of an XML Sitemap

A properly formatted XML sitemap includes several essential elements:

  • <loc> – The full URL of the page
  • <lastmod> – The date the page was last modified
  • <changefreq> – How frequently the page is likely to change (though search engines largely ignore this)
  • <priority> – The relative importance of the page compared to other pages on your site (0.0 to 1.0)

Modern best practice is to focus on the URL and last modified date, as these provide the most actionable information to crawlers.

Why XML Sitemaps Matter for SEO

Understanding how to implement an effective sitemap directly impacts your site's crawl efficiency and indexation rate. Here's why sitemaps are critical:

  • Faster discovery – New and updated pages are found more quickly by search engines
  • Improved crawl efficiency – You help search engines prioritize which pages to crawl
  • Better coverage for large sites – Sites with thousands of pages benefit from clear crawl paths
  • Support for orphaned pages – Pages with few or no internal links can still be indexed
  • Rich media indexing – Sitemaps can include video, image, and news-specific metadata

When combined with other technical SEO best practices, a well-maintained sitemap forms the foundation of a healthy indexation strategy.

How to Create an XML Sitemap, Step by Step

Creating an XML sitemap doesn't require deep technical knowledge, but it does require attention to detail. Follow this guide to build one from scratch or audit your existing sitemap.

Step 1: Generate the Sitemap File

Most modern content management systems and website platforms can generate XML sitemaps automatically:

  • WordPress – Built-in sitemap functionality or plugins like Yoast SEO, Rank Math, or All in One SEO
  • Shopify – Automatically generated at yoursite.com/sitemap.xml
  • Wix and Squarespace – Auto-generated sitemaps available in site settings
  • Custom sites – Use server-side scripts or online sitemap generators

If you're building a sitemap manually, structure it with proper XML syntax and ensure it's saved with a .xml extension.

Step 2: Include Only Indexable Pages

Your sitemap should list only the pages you want search engines to index. Exclude:

  • Pages with noindex tags
  • Duplicate content or parameter-driven URLs
  • Redirect chains or broken links
  • Admin, login, or thank-you pages
  • Low-value tag or archive pages

A clean sitemap helps search engines focus on your most valuable content and avoids wasting crawl budget on irrelevant pages.

Step 3: Keep the File Size Manageable

XML sitemaps have technical limits:

  • Maximum 50,000 URLs per sitemap file
  • Maximum file size of 50 MB uncompressed

If your site exceeds these limits, use a sitemap index file that links to multiple smaller sitemaps. For example, you might have separate sitemaps for blog posts, product pages, and category pages.

Pro Tip

Use gzip compression to reduce sitemap file size by up to 90%. Search engines can read .xml.gz files natively, and compression improves load times and server bandwidth usage.

Optimizing Your Sitemap for Maximum Impact

Simply having an XML sitemap isn't enough—you need to optimize it for search engine efficiency. This section covers advanced best practices.

Use Accurate Last Modified Dates

The <lastmod> tag tells search engines when a page was last updated. If this date changes frequently without meaningful content updates, crawlers may deprioritize your site. Only update this value when substantive changes occur.

Prioritize Strategic Pages

While the <priority> tag has limited impact, setting high-priority values (0.8–1.0) for your most important pages—such as cornerstone content or high-converting landing pages—can signal their relative importance within your site structure.

Segment by Content Type

Creating separate sitemaps for different content types improves organization and allows you to track indexation by category. Common segmentation strategies include:

  • Blog posts
  • Product pages
  • Category and tag archives
  • Static pages (about, contact, services)
  • Media files (images, videos)

How to Submit Your Sitemap to Search Engines

After creating and optimizing your sitemap, you need to submit it to search engines to ensure they discover it.

Submit to Google Search Console

Google Search Console provides a dedicated sitemap submission tool. Navigate to the "Sitemaps" section under "Indexing," enter your sitemap URL (e.g., https://yoursite.com/sitemap.xml), and click Submit. Google Search Console tools will then monitor your sitemap for errors and track indexation status.

Submit to Bing Webmaster Tools

Bing Webmaster Tools has a similar process. Log in, select your site, and navigate to "Sitemaps" under the "Configure My Site" section. Paste your sitemap URL and submit it.

Reference in Robots.txt

Add a reference to your sitemap in your robots.txt file to help any crawler discover it automatically:

Sitemap: https://yoursite.com/sitemap.xml

This line should appear at the end of your robots.txt file and supports multiple sitemap declarations if you use a sitemap index.

Common XML Sitemap Mistakes to Avoid

Even experienced site owners make sitemap errors that can hurt indexation. Watch out for these common pitfalls:

  • Including noindexed pages – These send mixed signals to crawlers
  • Listing redirect URLs – Only include final destination URLs
  • Broken or 404 links – Regularly audit your sitemap for dead links
  • Ignoring mobile versions – Ensure mobile URLs are included if you have a separate mobile site
  • Forgetting to update – Sitemaps should reflect current site structure
  • Overly large sitemaps – Break them into smaller, focused files

Monitoring and Maintaining Your Sitemap

A sitemap strategy is not complete without a maintenance plan. Your sitemap should evolve as your site grows and changes.

Set up regular checks to:

  • Validate XML syntax using online validators
  • Review indexation reports in Search Console to identify coverage issues
  • Remove outdated or deleted pages promptly
  • Add new pages within 24–48 hours of publication
  • Monitor crawl stats to ensure efficient use of crawl budget

Automated SEO platforms can streamline this process by flagging sitemap errors, tracking changes, and notifying you when action is needed.
